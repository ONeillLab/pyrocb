# Compilation

## Compiling WRF-SFIRE for ideal cases on a personal computer (Linux)
Running script [``scripts/compile/personal-ideal.sh``](/scripts/compile/personal-ideal.sh) will compile WRF-SFIRE for your personal computer. WRF's compile log will be outputted to [``/out/logs/compile/compile.log``](/out/logs/compile/compile.log).

*This script can take upwards of an hour.*

## Compiling WRF-SFIRE for real cases on Nibi

Running script [``scripts/compile/nibi-real.sh``](/scripts/compile/nibi-real.sh) will compile WRF-SFIRE for [DRA's Nibi computer](https://docs.alliancecan.ca/wiki/Nibi). WRF's compile log will be output to [``/out/logs/compile/compile.log``](/out/logs/compile/compile.log).

*Adapted from Running WRF-FIRE for real data cases on trillium by Micah Yoon and Noah Vaillant*
